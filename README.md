# SkillCraft Technology Internship - Task 01

## Population Distribution Visualization Using Python

### Project Overview

This project focuses on visualizing population data using Python. The objective is to understand the distribution of demographic variables through graphical representations and statistical analysis.

### Objective

To create visualizations that represent the distribution of categorical and continuous variables using Python data visualization libraries.

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

### Dataset Information

The dataset contains demographic information including:

* Age
* Gender

### Visualizations Performed

1. Histogram for Age Distribution
2. Bar Chart for Gender Distribution
3. Pie Chart for Gender Percentage Distribution

### Statistical Analysis

* Average Age: 38.67 Years
* Maximum Age: 59 Years
* Minimum Age: 18 Years

### Key Insights

* The age distribution was analyzed using a histogram.
* Gender distribution was compared using bar and pie charts.
* Visualizations helped identify patterns and trends within the population dataset.

### Conclusion

This project demonstrates the importance of data visualization in understanding population demographics. Using Python and Matplotlib, meaningful insights were extracted from the dataset through graphical analysis and statistical measures.
