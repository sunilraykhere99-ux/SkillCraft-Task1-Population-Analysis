# SkillCraft Technology - Task 01

## Population Distribution Visualization

### Objective

Create visualizations to analyze the distribution of population data using Python.

### Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

### Visualizations

* Histogram (Age Distribution)
* Bar Chart (Gender Distribution)
* Pie Chart (Gender Percentage Distribution)

### Results

* Average Age: 38.67
* Maximum Age: 59
* Minimum Age: 18

### Conclusion

The project demonstrates how data visualization can be used to understand demographic distributions and identify patterns in population data.
